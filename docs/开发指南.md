# 开发指南

## 一、本地环境准备

### 1.1 必装软件

| 软件 | 版本 | 下载 |
|------|------|------|
| Python | 3.11+ | https://www.python.org/downloads/ |
| uv | 最新 | PowerShell: `irm https://astral.sh/uv/install.ps1 \| iex` |
| PostgreSQL | 16 | https://www.postgresql.org/download/windows/ |
| Node.js | 20+ | https://nodejs.org/ |

> Celery / Redis 在 `INGEST_MODE=sync` 模式下**不需要**，本地开发直接跳过。

### 1.2 数据库初始化

安装 PostgreSQL 后，打开 psql 执行：

```sql
CREATE USER rag_user WITH PASSWORD 'rag_pass';
CREATE DATABASE rag_db OWNER rag_user;
GRANT ALL PRIVILEGES ON DATABASE rag_db TO rag_user;
```

### 1.3 API Key 准备

- **DeepSeek**：https://platform.deepseek.com/api_keys
- **阿里云 DashScope**：https://dashscope.console.aliyun.com/apiKey（新用户有免费额度）

## 二、首次启动

```powershell
# ── 后端 ──
cd C:\工作\AI项目\RAG\backend
uv sync                                # 安装依赖（含 bcrypt/jose/FlagEmbedding 等）
copy .env.example .env                 # 复制配置，编辑填入 Key
.venv\Scripts\alembic upgrade head     # 应用所有迁移（建表）

# 启动 API（新终端）
.venv\Scripts\uvicorn app.main:app --reload --reload-dir app
# 首次启动自动创建 admin 账号，日志显示：

# ── 前端 ──
cd C:\工作\AI项目\RAG\frontend
npm install
npm run dev
```

打开浏览器：
- http://localhost:5173 — 前端（需登录）
- http://localhost:8000/docs — Swagger UI（无需登录，可测试接口）

## 三、认证与用户

### 3.1 默认账号

| 用户名 | 密码 | 权限 |
|--------|------|------|
| `admin` | `admin123` | 管理员（is_admin=true） |

**首次登录后请立即通过「用户管理」页重置密码。**

### 3.2 JWT 机制

- 登录接口：`POST /api/auth/login`，Body：`{"username": "...", "password": "..."}`
- 返回：`{"access_token": "eyJ...", "token_type": "bearer"}`
- 所有业务接口请求头须带：`Authorization: Bearer <token>`
- Token 有效期：`JWT_EXPIRE_DAYS`（默认 7 天）
- `is_admin` 字段编码在 JWT payload 内，前端通过 base64 解码读取，无需额外请求

### 3.3 用户管理 API（Admin only）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/users` | 用户列表 |
| POST | `/api/admin/users` | 创建用户（password 留空则自动生成） |
| PATCH | `/api/admin/users/{id}` | 修改 is_active / is_admin |
| POST | `/api/admin/users/{id}/reset-password` | 重置密码（返回明文，仅一次） |
| DELETE | `/api/admin/users/{id}` | 删除用户 |

## 四、Alembic 迁移管理

项目已有 4 条迁移记录，**不要**再执行 `alembic revision --autogenerate`，直接 `upgrade head` 即可：

```
a18685b9d090  init（建 kb/document/chunk/conversation/message 表）
7db07637bba2  extend_doc_field_lengths
c3f8a12e9d45  add users table
e9b2d3c4f501  add is_admin to users   ← 当前 HEAD
```

### 新增数据库字段的正确流程

```powershell
# 1. 改 app/models/xxx.py
# 2. 手动编写迁移（参考已有版本），不要用 autogenerate（路径问题可能导致无法导入）
# 3. 应用
.venv\Scripts\alembic upgrade head
# 4. 验证
.venv\Scripts\alembic current
```

### 迁移已应用但表已存在（DuplicateTableError）

说明 DB 里已有该表但 alembic 版本记录落后，用 `stamp` 跳过：

```powershell
.venv\Scripts\alembic stamp <revision_id>   # 标记为已完成
.venv\Scripts\alembic upgrade head           # 继续执行后续迁移
```

## 五、Reranker 说明

### 5.1 模型信息

- 模型：`BAAI/bge-reranker-v2-m3`（约 2GB）
- 首次启动时从 https://hf-mirror.com 自动下载，保存至 `~/.cache/rag_models/bge-reranker-v2-m3/`
- 下载完成后自动加载 + 预热（首次加载约 1~3 分钟，后续秒级）

### 5.2 性能参数

```dotenv
RETRIEVE_TOP_K=10     # Qdrant 召回候选数（减少此值可加快 rerank 速度）
RERANK_TOP_K=5        # rerank 后保留条数（进入 LLM prompt 的文档数）
```

`compute_score` 固定使用 `max_length=256`（原 512），推理时间减半。

### 5.3 流程

```
用户提问
  → Qdrant 向量检索 Top-10（余弦相似度，~100ms）
  → bge-reranker-v2-m3 精排 Top-5（cross-encoder，~5~10s）
  → 拼 Prompt → DeepSeek 流式生成
  → SSE 输出 token + citations
```

## 七、常见问题

### Q: 登录报 401 / 密码错误

检查 `.env` 里 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 是否与数据库里的一致。
如果 users 表是手动建的（而非通过 lifespan 自动创建），密码字段必须是 bcrypt hash，不能是明文。

### Q: `password cannot be longer than 72 bytes`

passlib 与 bcrypt>=4.0 版本不兼容。项目已改为直接使用 `bcrypt` 库（`security.py`），
如果仍报此错，检查是否有旧版 `security.py` 未更新（其中不应再出现 `CryptContext`）。

### Q: Reranker 首次启动卡住没有日志

原因：torch 在 Windows 非主线程首次 import 时会触发线程锁。
解决：`main.py` 顶部已在 asyncio 启动前 `import FlagEmbedding`，勿删除这几行。

### Q: Reranker 下载卡住/失败

设置镜像后仍失败，可手动下载：
```powershell
.venv\Scripts\python -c "
from huggingface_hub import snapshot_download
snapshot_download('BAAI/bge-reranker-v2-m3',
    local_dir=r'C:\Users\hp\.cache\rag_models\bge-reranker-v2-m3',
    endpoint='https://hf-mirror.com')
"
```

### Q: `is_admin 字段不存在` 错误

未执行最新迁移，运行：
```powershell
.venv\Scripts\alembic upgrade head
```

### Q: 本地 bge-m3 Embedding 首次加载特别慢

首次从 HuggingFace 下载约 2GB。可改用 `EMBEDDING_PROVIDER=dashscope` 走 API。

### Q: 切换 Embedding 模型后老知识库检索结果乱

不同 Embedding 的向量空间不兼容，切换前须删除旧知识库并重新入库。

### Q: 非 admin 用户访问 `/users` 页面

路由守卫会自动跳转到首页，不会显示错误页。
`/api/admin/*` 接口返回 403，不影响其他功能。

### Q: SSE 流式响应在代理后面不实时

Nginx 需配置：
```nginx
proxy_buffering off;
proxy_cache off;
proxy_set_header Connection '';
chunked_transfer_encoding on;
```
